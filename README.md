# 台股快速看板

給短線投資客用的簡易台股看盤工具，介面單純：新增股票代碼，就能看到目前股價、漲跌、成交量。

## 使用方式

需要先安裝 [Node.js](https://nodejs.org/)（開發時用的是 v24）。

```bash
node server.js
```

啟動後，用瀏覽器打開 http://localhost:3000 即可。

## 功能

- 頁面上方顯示大盤加權指數，即時掌握盤勢
- 輸入股票代碼（例如 2330）新增追蹤
- 顯示成交價、漲跌、漲跌幅、開高低、成交量
- 頁面上方顯示美元指數（DXY），掌握外資、匯率環境
- 紅漲綠跌，符合台灣習慣
- 每 15 秒自動更新一次，也可手動按「重新整理」
- 按「依漲跌幅排序」可切換漲跌幅排行（高到低 / 低到高 / 預設順序），排行時會顯示名次
- 追蹤清單存在瀏覽器本機（localStorage），關掉重開還在
- 點「走勢圖」可展開近三個月收盤價走勢圖

## 資料來源

- 股票：證交所盤中即時揭示 API（延遲約 5 分鐘），僅供參考，非投資建議。目前只支援上市（TSE）股票，尚未支援上櫃（OTC）。
- 美元指數：Yahoo Finance 公開報價 API（DX-Y.NYB）。
